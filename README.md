# java-racingcar-precourse

## 구현 기능 목록
1. 입력/검증
    - [ ]  이름 문자열을 입력받음
    - [ ]  쉼표로 구분하여 각 이름을 나눔
    - [ ]  쉼표로 구분된 각 공간이 빈 칸이 아닌지, 5자 이하인지 검증
      (throws `IllegalArgumentException`)
    - [ ]  시도 횟수 입력받음
    - [ ]  시도 횟수가 `Integer` 이고 1 이상인지 검증(throws `IllegalArgumentException`)
2. 도메인 동작
    - [ ]  전진 시도 수행_0~9의 무작위 정수를 뽑아 4이상이면 전진
    - [ ]  라운드마다 각 자동차가 전진 시도를 1회 수행
    - [ ]  전진 시도 성공시 자동차의 위치값을 +1 함
    - [ ]  지정된 시도 횟수만큼 전체 라운드 진행
3. 출력
    - [ ]  각 라운드가 끝날 때마다 차수별 실행 결과 출력
    - [ ]  모든 라운드 종료후 최종 우승자(들) 출력
4. 우승자 판정
    - [ ]  자동차의 위치값이 최대인 자동차를 찾아 반환(동일 최대값이 여러 대면 공동 우승 처리)
5. 예외 및 종료
    - [ ]  오입력 시 `IllegalArgumentException` 을 throw 하고 애플리케이션 종료
