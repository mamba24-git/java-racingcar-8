# java-racingcar-precourse

## 구현 기능 목록
1. 입력 및 검증
   - [x]  이름 문자열을 입력받음
   - [ ]  쉼표로 구분하여 각 이름을 나눔
   - [ ]  쉼표로 구분된 각 공간이 빈 칸이 아닌지, 5자 이하인지 검증
   - [x]  시도 횟수 입력받음
   - [ ]  시도 횟수가 `Integer` 이고 1 이상인지 검증
2. 도메인 동작
   - [ ]  전진 시도 수행_0~9의 무작위 정수를 뽑아 4이상이면 전진
   - [ ]  라운드마다 각 자동차가 전진 시도를 1회 수행
   - [ ]  전진 시도 성공시 자동차의 위치값을 +1 함
   - [ ]  지정된 시도 횟수만큼 전체 라운드 진행
3. 출력
   - [ ]  각 라운드가 끝날 때마다 차수별 실행 결과 출력
   - [ ]  모든 라운드 종료후 최종 우승자(들) 출력
4. 우승자 판정
   - [ ]  자동차의 위치값이 최대인 자동차를 찾아 반환(동일 최대값이 여러 대면 공동 우승 처리)
5. 예외 및 종료
   - [ ]  오입력 시 `IllegalArgumentException` 을 발생시키고 애플리케이션 종료
6. 테스트
   - [ ]  이름 파싱 및 검증 (길이, 빈값, 구분자 형식(쉼표))
   - [ ]  시도 횟수 검증 (정수, 1 이상 `MAX_VALUE` 이하)
   - [ ]  전진 시도 성공 및 실패 (난수 4 이상 전진, 3 이하 정지)
   - [ ]  전진 시도 성공 및 실패 시 자동차 위치 이동 수치 검증
   - [ ]  여러 라운드 진행 시 자동차 위치(누적 이동 수치) 검증
   - [ ]  단독/공동 우승 판정 검증
   - [ ]  출력 포맷 테스트
